# Conventions

A convention answers "how do we normally do things here" — naming, structure, recurring patterns. Distinct
from a fact (`.juntia/context.md`, what's true about the project) and a decision (`.juntia/DECISIONS.md`,
what was deliberately chosen and why): a convention is a *pattern to follow*, not a record of what already
exists or was decided once.

This directory is scaffolded as an empty contract, deliberately — Phase 15B (`phases/15b-knowledge-layer.md`)
found no existing, real convention content anywhere to migrate, and did not invent one to fill this directory.
Add a file here (e.g. `naming.md`, `testing.md`) once your project has a real, recurring pattern worth
writing down — an invented-sounding convention with no real precedent is worse than an empty directory,
because it will get treated as settled.
